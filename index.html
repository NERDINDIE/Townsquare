🛡️ Layered Architecture Resilience

Townsquare OS implements four distinct layers of fault tolerance:

  • Global Uncaught Exception Trap: Isolates background coroutines from the main UI thread.
  • Compose Safe Error Boundaries: Self-heals visual composition crashes with 1-click retry.
  • Looper Latency Watchdog: Captures thread stack traces on freeze (>1,200ms).
  • Dynamic Memory Reclamation: Evicts stale bitmap buffers on system low-memory signals.
